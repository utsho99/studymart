# StudyMart 📚

StudyMart is a student marketplace built for Bangladesh, where students can buy and sell used books, notes, calculators, and other study materials.

### Features

* Buy & sell study materials
* Upload and share notes
* Real-time chat between buyers and sellers
* User profiles and authentication
* Search and browse listings

### Tech Stack

* React + Vite + Tailwind CSS
* Node.js + Express.js
* MongoDB + Mongoose
* JWT Authentication
* Socket.io

### Quick Start

```bash
# Backend
cd backend
npm install

# Frontend
cd frontend
npm install
```

Run the development servers:

```bash
# Backend
npm run dev

# Frontend
npm run dev
```
